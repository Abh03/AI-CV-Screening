# Stage 3 evidence ID protocol

Prompt v13 uses `SentenceSelectionOutput` for configured real providers. The provider supplies scores, suitability rationales, selected sentence IDs, flags and a summary. It cannot supply factual claims or quotations. Python constructs each factual claim and quote verbatim from the selected complete sentence. Request-local category schemas enumerate only supplied IDs. Flags enumerate all supplied IDs; career-gap flags are additionally checked against EXPERIENCE ownership.

Sentence IDs bind candidate ownership, assessment category, original document/chunk identity, source category/location/text and sentence offsets. They survive retrieval reordering and cannot be reused across candidates or categories. `sentence_start` and `sentence_end` are offsets in the original chunk; `source_location` retains the parent chunk's provenance. PDF line wraps and decimals do not become sentence boundaries. Sentence segmentation is lexical and conservative; unpunctuated lists/role headers remain together. Omitted passages are never selectable.

The bounded prompt and resolver share the same immutable registry. Provider facts are built from that registry, never from output text. Unknown IDs, incorrect categories, missing evidence/coverage, injection signals, incomplete context and material flags retain their review requirements. Positional tags remain internal verification compatibility keys and are not selectable IDs.

Historical v12 `EvidenceSelectionOutput` responses remain readable with `source-excerpt-v1` checks: case/whitespace-normalized contiguous excerpts must retain recognized negation and limiting qualifiers. Unsupported paraphrases, added numbers, fabricated quotations and invalid citations remain rejected. Legacy replay does not migrate or repair historical provider prose. Injected/custom legacy test providers retain that compatibility path.

Provider budgets include system prompt, escaped XML, schema, IDs, chat framing and completion allowance, using conservative estimates and configurable ceilings. Mandatory requirements and complete role/project sections receive priority. Omissions remain recorded and force review; a smaller HTTP 413 recovery request uses a newly bounded registry and schema.

Deterministic factual construction does not prove arbitrary rationale/summary prose or suitability scores. Model judgments must stay within selected facts; human review remains necessary for uncertainty, incomplete context and material flags. Mock evaluations retain their synthetic format and development/test restriction.
